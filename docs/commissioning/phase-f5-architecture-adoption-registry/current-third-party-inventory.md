# Current third-party inventory

The generated supply-chain inventory reconciles direct and transitive Python runtime/build packages and Node runtime/development packages from committed locks. Every direct root has a human-reviewed adoption record. F5 also records Foundry Anvil, immutable GitHub Actions pins, Hyperliquid public endpoints, and optional requester-pays HyperCore data acquisition.

Licenses and provenance are evidence records, not legal conclusions. Unknown active direct provenance or license evidence blocks validation. Service terms are deliberately distinct from open-source licenses.
